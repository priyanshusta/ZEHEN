// Voice agent

Say "Zehen". It does the rest.

The wake word runs on your PC using your personal three-sample MFCC voice profile and Vosk, and only fires at the start of a phrase. Pick a request to trace the loop (recorded walkthrough).

Hear

MFCC/DTW + Vosk wakes on the first word. Local faster-whisper (~0.4 s) transcribes on CPU, or Groq Whisper with a Groq key.

Plan

A language model replies in strict JSON. Anything outside the validated action schema is dropped.

Act

Apps, shortcuts, UI Automation clicks by control name, web links, and PowerShell — up to six steps per request.

Say

Kokoro 82M, an offline neural voice, reads the answer and listens briefly for a follow-up.

// Pipeline

From light to action in 33 ms.

See

The camera frame is mirrored and handed to MediaPipe in RAM, never saved or displayed.

Track

21 landmarks per hand, both hands, every frame, fully on-device at camera speed.

Understand

Act

Real Win32 mouse, wheel, and keystrokes, plus the translucent HUD so you always see what fired.

// Privacy and safety

Local first. Honest about the rest.

  • Camera frames are processed in memory and discarded. Never shown, saved, or uploaded.
  • The wake word runs on your PC. Audio is captured only after you say "Zehen".
  • With the offline Qwen3 model or local Ollama, zero request data leaves your PC.
  • Built-in safety guard blocks catastrophic system commands and asks for spoken confirmation before destructive actions (file deletion, process kill, Recycle Bin, shutdown). Make a fist to pause, or set "voice": false.
  • No accounts, no telemetry, no ads. MIT licensed.

// FAQ

Questions people ask.

Is ZEHEN a free, open-source Tony Stark / J.A.R.V.I.S. for Windows?

Yes. ZEHEN is MIT licensed, completely free with no paid tier or account, and inspired by Tony Stark's J.A.R.V.I.S. and holographic HUD. You can control the cursor with hand gestures through your webcam and command Windows by voice with local or free cloud AI planning.

Can I control my computer as a webcam virtual mouse without gloves or Leap Motion?

Yes. ZEHEN uses MediaPipe to track 21 landmarks per hand from any standard laptop or USB webcam and drives the real Windows mouse cursor, clicks, dragging, scrolling, zoom, app switching, and air-writing. No gloves, IR sensors, or depth cameras are required.

Does ZEHEN work offline with a local LLM or Ollama?

Yes. Hand tracking, handwriting recognition, wake-word detection, local speech-to-text (faster-whisper), neural TTS (Kokoro 82M), and planning via the built-in 1.1 GB Qwen3 1.7B model all run offline. You can also point the llm config at any local OpenAI-compatible server such as Ollama or LM Studio.

How does ZEHEN click inside apps without screenshots or a vision model?

ZEHEN reads Windows UI Automation trees to discover buttons, tabs, text fields, and list items by accessible name in plain text, keeping memory usage near 0.7 GB without running a multimodal vision model.

Is ZEHEN really free and private?

Yes. Camera frames are never saved, shown, or uploaded. All telemetry, ads, and accounts are absent. Using the offline Qwen3 model keeps 100% of voice and system context on your device.

It does not wake when I say "Zehen" — how do I fix it?

Run voice enrollment (say "learn my voice") so ZEHEN matches your personal three-sample MFCC profile, and speak "Zehen" at the start of a phrase rather than mid-sentence. Before enrollment, you can add phonetic spellings to wake in .zehen.json.

Does ZEHEN work on macOS or Linux?

Not yet. Window automation, Start menu lookup, Windows ink handwriting recognition, and UI Automation are currently Windows-specific. Cross-platform support is tracked in the roadmap.
